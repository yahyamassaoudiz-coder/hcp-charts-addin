HCP Charts

Des graphiques modifiables à partir des statistiques du Haut-Commissariat au Plan (data.gov.ma).

En ligne, sans installation

Choisissez vos indicateurs, puis téléchargez le graphique en .pptx (graphique PowerPoint modifiable) ou en .svg.

Créer un graphique

Dans PowerPoint

Le complément ajoute un bouton HCP Charts et insère le graphique dans votre présentation, aux couleurs de votre thème.

Télécharger le complément

  1. Téléchargez le fichier ci-dessus.
  2. PowerPoint → Accueil (ou Insertion) → Compléments → Mes compléments → Charger mon complément.
  3. Choisissez le fichier. Le bouton HCP Charts apparaît dans l'onglet Insertion.

Pour toute une organisation : Centre d'administration Microsoft 365 → Applications intégrées → Charger des applications personnalisées → même fichier.
