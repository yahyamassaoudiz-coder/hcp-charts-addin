HCP Charts - PowerPoint add-in
==============================

WINDOWS
 1. Unzip this folder (right-click > Extract All).
 2. Double-click "Install HCP Charts.bat".
    If Windows shows "Windows protected your PC": More info > Run anyway.
 3. Close PowerPoint completely and open it again.
 4. Insert tab > HCP Charts.

MAC
 1. Right-click "Install HCP Charts (Mac).command" > Open > Open.
 2. Quit PowerPoint (Cmd+Q), reopen it.
 3. Insert > Add-ins > My Add-ins > HCP Charts.

REMOVE (Windows): double-click "Uninstall HCP Charts.bat".

No admin rights needed. Needs an internet connection when used:
the add-in loads from https://yahyamassaoudiz-coder.github.io/hcp-charts-addin/
No install needed at all: open that address and click "Creer un graphique".
